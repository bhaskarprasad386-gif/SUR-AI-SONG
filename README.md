# Sur AI Studio

**Hindi-first AI songwriting, voice studio, music arrangement and music-video workspace.**

Sur AI Studio is being built as a step-by-step creative studio:

1. **Songwriter** — define a story, language and mood; edit the lyrics draft.
2. **Voice Lab** — upload a voice sample and prepare a clean vocal workflow.
3. **Music Director** — choose a reference track, tempo, vocal arrangement and multi-track layers.
4. **Music Video Studio** — add photos/video clips and prepare a lyric/cinematic video timeline.

## Current build status

The first responsive React/Vite interface is in place. Lyrics can be edited, voice/reference audio and photo/video files can be selected locally, and music layers can be toggled in the UI.

**Important:** the current build is a front-end prototype. The sample lyrics are a local demo; they are not generated by a connected AI model. AI lyric generation, audio analysis, voice enhancement/conversion, original music generation, multi-stem rendering, persistent projects and final MP4 export still need backend/model integrations.

Reference tracks should be used to derive broad attributes (tempo, mood, instrumentation and arrangement). Create an original composition rather than copying a reference song's exact melody, recording or a real singer's identity.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Planned architecture

- **Frontend:** React + Vite, responsive dark studio UI.
- **Backend:** authenticated API for project state, upload handling, job status and provider adapters.
- **AI adapters:** swappable lyric, speech enhancement/voice conversion, audio understanding and music-generation providers. Keep API keys server-side; never place secrets in Vite client variables.
- **Audio pipeline:** vocal cleanup, pitch/timing tools, vocal layers, stems, mixing and WAV/MP3 output.
- **Video pipeline:** lyric timing, image/video tracks, transitions, effects, audio sync and MP4 rendering.
- **Storage:** private project assets and exports, with explicit user controls.

## Build sequence

1. Make the UI and project data flow reliable.
2. Add backend and secure upload/job APIs.
3. Connect lyric generation and reference-track feature analysis.
4. Add consent-based voice enhancement and original vocal/music generation.
5. Add multitrack mixing, project saving and video rendering.
6. Test, deploy and verify the complete workflow.

No API keys or private voice samples should be committed to this repository.
